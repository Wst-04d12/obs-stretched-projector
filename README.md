### OBS Stretched Projector Plugin for Windows x86_64  
  
### Usage:  
1. Decompress the ZIP attached in Release.  
2. Goto  `Tools` > `Scripts` > `+`   and select `osp.lua` that you just got from the decompression.
3. Use `Enable Projector Stretching` toggle on the right (under `Description`).  
  
### Build From Source:  
Compile `osp.c` as DLL named `obs_stretched_projector.dll` and place it alongside with `osp.lua` and you are good to go.
